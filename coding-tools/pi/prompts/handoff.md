description: Write a handoff brief for a fresh session
argument-hint: "[next task]"
---
Write `HANDOFF.md` in the repo root so a fresh agent can continue without reading this transcript.

Include:
- Goal and current status (done / in progress / blocked)
- Files changed and why
- Decisions made and alternatives rejected
- Exact commands that reproduce the current state and verify it
- Known failures, open questions, and the next concrete step $@

Keep it under 60 lines. Use real paths and real commands. Then confirm the file was written.
